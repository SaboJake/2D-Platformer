# 2D Platformer

## 1. Description
* This is an older project implemented in Godot 3.4
* Mega Man X styled physics using animations and sprite sheets from the games
* Features all movement options (jumping, wall jumping, dashing, etc.) as well as shooting and charging
* Can switch armors and weapons (only visual effect)
* Basic UI including life and weapon anergy and a pause menu

## 2. How to run
* Download Godot 3.4.3, load the project, select the scene DebugLevel.tscn and run (F6)
